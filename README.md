# Symbiote

Tauri 2 desktop app with React 19, TypeScript, TanStack Router, Tailwind CSS v4, and Bun.

## Development

| Task                | Command             |
| ------------------- | ------------------- |
| Frontend dev server | `bun run dev`       |
| Tauri dev           | `bun run tauri dev` |
| Build               | `bun run build`     |
| Test                | `bun test`          |
| Lint                | `bun run lint`      |
| Format              | `bun run format`    |
| Typecheck           | `bunx tsc --noEmit` |

## IDE

Recommended: VS Code with Oxc, Tailwind CSS IntelliSense, rust-analyzer, and Tauri extensions (see `.vscode/extensions.json`).
