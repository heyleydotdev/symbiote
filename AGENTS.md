# Agent Instructions

## Package Manager

- Bun (`bun.lock`): `bun install`

## Commands

| Task         | Command                                            |
| ------------ | -------------------------------------------------- |
| Dev (Vite)   | `bun run dev`                                      |
| Dev (Tauri)  | `bun run tauri dev`                                |
| Build        | `bun run build`                                    |
| Test         | `bun test`                                         |
| Test file    | `bun test path/to/file.test.ts`                    |
| Lint         | `bun run lint`                                     |
| Lint file    | `bunx oxlint path/to/file.ts`                      |
| Format       | `bun run format`                                   |
| Format check | `bun run format:check`                             |
| Typecheck    | `bunx tsc --noEmit`                                |
| Rust check   | `cargo check --manifest-path src-tauri/Cargo.toml` |

## Key Conventions

- Frontend: React 19 + TypeScript; file-based routes in `src/routes` (TanStack Router).
- Styling: Tailwind CSS v4, entry point `src/globals.css`.
- Rust backend: `src-tauri/src`; register `#[tauri::command]`s in `lib.rs`.
- Tauri commands return `Result<T, E>`; wrap `invoke` calls in typed helpers under `src/lib`.
- Tests: `*.test.ts` colocated with source, run with `bun test`.
- `src/routeTree.gen.ts` is generated by the router plugin — never edit it.
- Formatter/linter configs: `.oxfmtrc.json`, `.oxlintrc.json`.
