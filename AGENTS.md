# Agent Instructions

## Package Manager

- Bun (`bun.lock`): `bun install`

## Commands

| Task         | Command                                            |
| ------------ | -------------------------------------------------- |
| Dev (Vite)   | `bun run dev`                                      |
| Dev (Tauri)  | `bun run tauri dev`                                |
| Build        | `bun run build`                                    |
| Test         | `bun test`                                         |
| Test file    | `bun test path/to/file.test.ts`                    |
| Lint         | `bun run lint`                                     |
| Lint file    | `bunx oxlint path/to/file.ts`                      |
| Format       | `bun run format`                                   |
| Format check | `bun run format:check`                             |
| Typecheck    | `bunx tsc --noEmit`                                |
| Rust check   | `cargo check --manifest-path src-tauri/Cargo.toml` |

## Key Conventions

- Frontend: React 19 + TypeScript; file-based routes in `src/routes` (TanStack Router).
- Styling: Tailwind CSS v4, entry point `src/globals.css`.
- Rust backend: `src-tauri/src`; register `#[tauri::command]`s in `lib.rs`.
- Tauri commands return `Result<T, E>`; wrap `invoke` calls in typed helpers under `src/lib`.
- Tests: `*.test.ts` colocated with source, run with `bun test`.
- `src/routeTree.gen.ts` is generated by the router plugin — never edit it.
- Formatter/linter configs: `.oxfmtrc.json`, `.oxlintrc.json`.

## Learning more about Effect

This repository uses the Effect Typescript library.

Before writing any Effect code, first read `node_modules/effect/AGENTS.md` **completely**, and follow the links in the file when required.

If you need to learn more about particular Effect apis and concepts that the guide doesn't cover, search through the source code in `node_modules/effect/src`.

## Agent skills

### Issue tracker

Issues live in GitHub Issues (`heyleydotdev/symbiote`), driven by the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical roles, each label equal to its name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### UI components (ui-sdk)

Follow the `ui-sdk` skill if it's installed. For each component you use, read `node_modules/@ui-sdk/react/docs/components/<entry>.md`; `llms.txt` is only the index.

To build a component ui-sdk doesn't ship, search `node_modules/@ui-sdk/react/docs/core.md` by heading, and read `rendering.md` next to it.

Components come per-entry (`@ui-sdk/react/button`), never from a root import. They are unstyled; style them with Tailwind utilities, not class names.
